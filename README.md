# Camp Quest — Summer Adventure

Open-ended drag-and-drop ESL A1 game for Grades 1–2.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files from this folder** to the repository root. `index.html` must be in the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

No build step, npm package, framework, external font, library, or image host is required.

## Game design
- Mission 1: learners choose what they want to pack. No right/wrong answer.
- Mission 2: learners dress either camper however they choose.
- Mission 3: weather and action cards can be moved to any landscape.
- Mission 4: learners arrange their own campsite.
- Mission 5: learners create their own camp-day sequence.
- Mission 6: learners choose picture cards and make sentences to tell their story.

Desktop: drag items with the mouse.  
Touchscreen: drag with a finger.  
Alternative: click an item, then click a target.
